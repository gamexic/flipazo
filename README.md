# FLIPAZO

**Mira. Memoriza. ¡Flipa!** Juego de memoria de cartas en 3D para el navegador.

Juega: https://gamexic.github.io/flipazo/

- 8 niveles: de 4 a 18 pares. Las cartas se muestran de 5 a 10 segundos y luego se voltean.
- Señala los pares. Cada fallo te quita una de tus 3 vidas.
- 7 ediciones de cartas: Locuras, Zoo Disparate, Cocina Chiflada, Fantasía Absurda, Deporte Disparate, Cosas Raras y Mezcla Total.
- Rachas, sonidos y chispas. Funciona en móvil y escritorio.

Un solo archivo (`index.html`) con three.js desde cdnjs.
